# 📋 Виртуальная доска объявлений

Веб-приложение для обмена информацией в учебном заведении.

## 🚀 Быстрый старт

### Вариант 1: Запуск локально
1.  Скачайте репозиторий:
    ```bash
    git clone https://github.com/ваш-логин/virtual-board-school.git
    ```
2.  Откройте файл `index.html` в браузере (Chrome, Firefox, Edge)
3.  Готово! Приложение готово к использованию.

### Вариант 2: Онлайн-демо
Приложение доступно по ссылке:  
🔗 [https://ваш-логин.github.io/virtual-board-school/](https://ваш-логин.github.io/virtual-board-school/)

## 📖 Гид по использованию

### 🔐 Вход и регистрация
1.  Нажмите кнопку **«🔐 Вход»** в правом верхнем углу
2.  Для входа используйте демо-аккаунты из таблицы выше
3.  Для регистрации нового пользователя:
    -   Нажмите **«📝 Нет аккаунта? Зарегистрироваться»**
    -   Заполните: логин (email), пароль, ФИО, телефон, роль
    -   Нажмите **«✅ Войти»**
    -   После регистрации откроется почтовый клиент с уведомлением администратору

### 📝 Создание объявления
1.  Авторизуйтесь в системе
2.  Нажмите кнопку **«➕ Объявление»**
3.  Заполните форму:
    -   **Заголовок** (до 100 символов, должен содержать русский текст)
    -   **Тип**: Предложение / Спрос / Обмен
    -   **Категория**: Расписание, Родителям, Ученикам и др.
    -   **Описание** (до 1000 символов, осмысленный текст с пробелами)
    -   **Теги** (через запятую, например: `5 класс, математика`)
    -   **Контакты**: телефон (+7...), email, t.me/..., vk.com/...
4.  Нажмите:
    -   **«🚀 На модерацию»** — объявление отправится на проверку администратору
    -   **«💾 Черновик»** — сохраните без публикации

### 🔍 Поиск и фильтрация
-   **Поиск**: введите ключевое слово в поле «🔍 Поиск...» и нажмите «Найти»
-   **Фильтр по типу**: выберите «Спрос», «Предложение» или «Обмен»
-   **Сортировка**: «Сначала новые» или «Сначала старые»
-   **Теги**: введите тег в поле «Тег + Enter...» для фильтрации

### 👤 Личный кабинет
1.  Нажмите **«👤 Кабинет»** в меню
2.  Здесь вы увидите:
    -   Список ваших объявлений с их статусами
    -   Кнопку быстрого создания нового объявления
    -   Возможность редактировать черновики и отклонённые объявления

### 🛡 Админ-панель (только для администраторов)
1.  Войдите под аккаунтом администратора
2.  Нажмите **«⚙️ Админка»** в меню
3.  В таблице модерации:
    -   ✅ **Зелёная галочка** — одобрить объявление (оно станет видно всем)
    -   ❌ **Красный крестик** — отклонить объявление (останется только у автора)
4.  При одобрении/отклонении администратор получает уведомление

### 🗑️ Удаление объявления
-   **Автор** может удалить своё объявление в любой момент
-   **Администратор** может удалить любое объявление
-   Нажмите кнопку **«🗑️ Удалить»** в карточке объявления и подтвердите действие

### 📬 Подписка на рассылку
1.  В верхней части главной страницы найдите блок «📬 Подписаться на рассылку»
2.  Введите email и выберите категорию
3.  Нажмите «Подписаться»
4.  При публикации новых объявлений в выбранной категории вам придёт уведомление

## ⚙️ Технические особенности

-   **Хранение данных**: `localStorage` браузера (данные сохраняются на устройстве пользователя)
-   **Адаптивность**: сайт корректно отображается на ПК, планшетах и смартфонах
-   **Без сервера**: приложение работает полностью в браузере, не требует установки
-   **Безопасность**: базовая проверка прав доступа, валидация пользовательского ввода

## ❓ Частые вопросы

**❓ Почему после обновления страницы данные не пропадают?**  
Данные сохраняются в `localStorage` браузера. Они доступны только на этом устройстве и в этом браузере.

**❓ Почему не работает копирование телефона?**  
Убедитесь, что используете современный браузер (Chrome 80+, Firefox 75+, Edge 80+). В старых браузерах функция копирования может быть недоступна.

**❓ Как сделать, чтобы данные были доступны всем пользователям?**  
Для промышленного использования требуется серверная часть (PHP/Node.js) и база данных (MySQL). Данный прототип демонстрирует клиентскую логику.

**❓ Почему при регистрации открывается почта?**  
Используется протокол `mailto:` для отправки уведомления администратору. Это имитация — в реальной версии письма отправлялись бы автоматически через сервер.
